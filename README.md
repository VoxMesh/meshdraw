# MeshDraw

**Проверяемые розыгрыши на основе радиоданных сети MeshCore**

MeshDraw позволяет пересчитать результат розыгрыша по опубликованному проверочному пакету. Регистрация ещё не открыта. Условия участия и сроки появятся на странице конкурса перед открытием.

Адрес сайта после размещения — [voxmesh.github.io/meshdraw](https://voxmesh.github.io/meshdraw/).

## Состав репозитория

В `docs/` находится готовая статическая страница. В `meshdraw_public/` — Python-проверка публичного пакета, в `meshdraw_core/` — ядро v0.2 для отдельного формата локального расчёта. Архивная проверка использует профиль `archive-input-v1` и операции ядра для квантования и отображения на билеты.

Приём заявок, реестр участников и получение исходных наблюдений относятся к закрытому приложению. Этот репозиторий предоставляет страницу конкурса и исходники проверяющего компонента. Регистрация на странице недоступна.

## Локальная проверка

Нужен Python 3.12. Для тестов JavaScript нужен Node.js 22 или новее. Выполняйте команды из корня полученной копии в локальном терминале с правами текущего пользователя.

```text
python -B -E -S -m meshdraw_public tests/fixtures/synthetic/verification.json
python -B -E -S -m unittest discover -s tests -v
node --test tests/public_web_vectors.mjs
```

Первая команда пересчитывает отдельный учебный пакет и выдаёт `MATCH` с билетом `0002`. Учебный пакет находится в тестовых данных. Для просмотра страницы запустите сервер каталога сайта. Он слушает loopback-порт 8000. Остановка — Ctrl+C.

```text
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

Откройте [локальную страницу](http://127.0.0.1:8000/). Браузерный пересчёт использует Web Crypto и BigInt. При размещении `docs/` на GitHub Pages относительные ссылки работают под префиксом проекта.

## Состояние конкурса

Начальная страница читает `RELEASE.json` и `result.json`. Режим `NO_CONTEST` с `state: null` показывает статус до регистрации. После подготовки публичного экспорта обновите согласованные `RELEASE.json`, `result.json` и `verification.json` и пересчитайте контрольные суммы в `SHA256SUMS.json`. При отсутствии сохранённого результата `verification.json` содержит `null`. Статические ресурсы и вычислитель сохраняются.

После публикации результата кнопка «Пересчитать» проверяет хеши, выбирает записи, квантирует RSSI/SNR, собирает RF-байты и вычисляет билет. Номер отображается после совпадения расчёта с опубликованным пакетом и состоянием конкурса. Повтор и обновление страницы используют сохранённые данные.

`MATCH` означает совпадение расчёта на предоставленных данных. Происхождение и полнота данных независимо не подтверждены. Модель предполагает доверие к организатору и источнику. Совпадение расчёта не устанавливает криптографическую случайность или устойчивость к выбору входа организатором.
