# MeshDraw

MeshDraw позволяет пересчитать сохранённый результат розыгрыша по опубликованному проверочному пакету. В демонстрации используются вымышленные наблюдения RSSI/SNR, список учебных билетов и результат **0002**. Регистрация ещё не открыта.

Адрес демонстрации после размещения — [voxmesh.github.io/meshdraw](https://voxmesh.github.io/meshdraw/).

В `docs/` находится готовая статическая страница. Кнопка «Пересчитать» проверяет контрольные суммы, выбирает записи, квантирует RSSI/SNR, собирает RF-байты и вычисляет номер билета. Подробности расчёта и оба JSON доступны на странице. Перезагрузка и повторный пересчёт используют тот же пакет.

Python-код в `meshdraw_public/` проверяет тот же формат пакета. `meshdraw_core/` содержит ядро v0.2 и отдельный формат локального расчёта. Архивная проверка использует профиль `archive-input-v1` и операции ядра для квантования и отображения на билеты. Приём заявок, реестр участников и получение исходных наблюдений относятся к отдельному приложению.

## Локальная проверка

Нужен Python 3.12. Для проверки JavaScript нужен Node.js 22 или новее. Команды выполняются из корня полученной копии в терминале локального компьютера с правами текущего пользователя.

```text
python -B -E -S -m meshdraw_public docs/verification.json
python -B -E -S -m unittest discover -s tests -v
node --test tests/public_web_vectors.mjs
```

Первая команда выдаёт `MATCH` и вычисленный билет в `calculation.mapping.ticket`. Для локального просмотра запустите сервер для каталога сайта. Команда открывает порт 8000 на loopback, остановка — Ctrl+C.

```text
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

Откройте [локальную страницу](http://127.0.0.1:8000/). Для браузерного пересчёта нужны Web Crypto и BigInt. При размещении `docs/` на GitHub Pages страница использует относительные ссылки и работает под префиксом проекта.

## Что показывает проверка

`MATCH` означает совпадение расчёта на предоставленных данных. Происхождение и полнота данных независимо не подтверждены. Условия модели предполагают доверие к организатору и источнику. Совпадение расчёта не устанавливает криптографическую случайность или устойчивость к выбору входа организатором.

Лицензия MeshDraw пока не объявлена. [Зависимости и происхождение компонентов](Documentation/DEPENDENCIES.md).
