# Зависимости и компоненты

Python использует стандартную библиотеку. Тесты JavaScript используют встроенные модули Node.js. Страница использует API браузера, Web Crypto, BigInt и системные шрифты. SVG-знак встроен в HTML. Отдельные файлы шрифтов, изображения, пакеты npm, Python wheels и исполняемые файлы не поставляются.

Вычислитель, проверка архивного пакета и интерфейс относятся к MeshDraw. Python-модули архивного профиля выполняют локальную проверку. Тестовые наборы содержат искусственные наблюдения и билеты.

Лицензия MeshDraw пока не объявлена. Условия использования установленных Python, Node.js и браузера определяются их поставщиками.
